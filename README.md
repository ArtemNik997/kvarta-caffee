# Кварта — лендинг обжарки кофе

- **Сайт:** https://kvarta-caffee.vercel.app
- **Lighthouse (mobile):** `docs/lighthouse-mobile.html`
- **Журнал работы с ИИ:** `docs/ai-session.md`

Лендинг маленькой обжарки в Минске: ассортимент, подписка, доставка и самовывоз, форма заявки. Идея сайта: обжарка по четвергам, доставка по пятницам, зерно у клиента на 1–3 день.

## Стек

- **Next.js (App Router), React, TypeScript** — страница и API-роут `POST /api/lead` в одном проекте
- **Tailwind CSS** — вёрстка mobile-first, цветовая палитра в `globals.css`
- **next/font** (Onest, Alegreya) и **next/image** — шрифты с кириллицей и оптимизация фото
- **Upstash Redis** — хранение заявок и защита от дублей
- **Vercel** — хостинг
- **Telegram Bot API** — дублирование заявок менеджеру (подробности ниже)

## Форма и заявки

- Белорусский номер проверяется на клиенте и на сервере (источник истины — сервер).
- Повторная заявка с того же номера в течение 10 минут (в том числе двойной клик) новую запись не создаёт, пользователь видит успех.
- Ошибка отправки показывает понятное сообщение, кнопку «Повторить» и запасные контакты, введённые данные не теряются.
- Скрытое поле-ловушка отсекает простых ботов.

## Почему Upstash Redis

На Vercel код работает в serverless-функциях: файловая система не подходит для постоянной записи, поэтому файл или SQLite-файл потеряются между вызовами и деплоями. Upstash Redis подключается в пару кликов и работает по HTTP. Главное — операция `SET key value NX EX 600` атомарна: она занимает номер на 10 минут только если ключа ещё нет. Поэтому даже параллельные запросы дают ровно одну заявку, а отдельная таблица и блокировки не нужны.

## Откуда пришёл клиент

При заходе сохраняются `utm_*`, `yclid`, `fbclid`, `ad_id`, `adset_id`, `campaign_id`, `referrer` и страница входа. Новые рекламные метки заменяют старые, при заходе без меток прежние сохраняются. Всё уходит вместе с заявкой.

Примеры ссылок для рекламы:

```
Instagram:
https://kvarta-caffee.vercel.app/?utm_source=instagram&utm_medium=cpc&utm_campaign=autumn&utm_content={{ad.name}}&ad_id={{ad.id}}

Яндекс.Директ:
https://kvarta-caffee.vercel.app/?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}&yclid={yclid}
```

Макросы `{{...}}` и `{...}` подставляются рекламными кабинетами.

## Telegram

Интеграция написана (`lib/telegram.ts`): при наличии переменных окружения заявка отправляется в чат менеджера, ошибка Telegram не ломает приём заявки. **Сам бот не создан**, поэтому уведомления сейчас не отправляются. Чтобы включить: создать бота через @BotFather, указать токен и `chat_id` в переменных окружения Vercel (имена в `.env.example`).

## Допущения

- Контакты мастерской — заглушки (+375 29 000-00-00, @kvarta_roastery).
- Доставка до 50 BYN: «стоимость уточнит менеджер».
- Срока приёма заказов на пятницу нет: «Принимаем заявки всю неделю, развозим по пятницам».
- Состав подписки: менеджер уточняет сорта при звонке (поле «комментарий»).
- Телефон: принимаются мобильные коды 25, 29, 33, 44.
- Повторная заявка с того же номера за 10 минут = «успех» для пользователя, но новая запись не создаётся.
- Оплата: обсуждается с менеджером (онлайн-оплаты нет по брифу).

## Работа с ИИ

- **Что делал сам, а что ИИ:**
  - Сам: дизайн-направление, деплой на Vercel, текст, изображения, тестирование функционала
  - ИИ: каркас компонентов, настройка валидации, роутинг и настройка API
- **Что ИИ сделал неправильно:**
  - В форме использовал устаревший синтаксис: `tsx React.FormEvent<HTMLFormElement>`
- **Что я исправил:**
  - Заменил на актуальный синтаксис: `tsx React.SubmitEvent<HTMLFormElement>`
