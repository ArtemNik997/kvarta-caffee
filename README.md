# Заявки на заказ

Форма на странице `/form` принимает имя и белорусский номер телефона. Серверный обработчик `POST /api/lead` валидирует данные и сохраняет заявку в таблицу `leads` в Supabase Postgres.

## Подключение Supabase

1. Создайте проект Supabase.
2. В **SQL Editor** проекта выполните [`database/schema.sql`](./database/schema.sql), чтобы создать таблицу `leads` и включить Row Level Security.
3. В настройках проекта найдите URL проекта и секретный ключ `service_role` (в новых проектах это может называться secret key). Добавьте их как серверные переменные окружения:

   ```env
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=your-service-role-secret
   ```

   Локально сохраните их в `.env.local` в корне проекта. На Vercel добавьте их в **Settings → Environment Variables** для нужных окружений, затем создайте новый deployment.
4. Запустите проект локально:

   ```bash
   npm run dev
   ```

Ключ `service_role` обходит Row Level Security. Он используется только серверным обработчиком, поэтому никогда не добавляйте к нему префикс `NEXT_PUBLIC_`, не передавайте его в браузер и не коммитьте `.env.local`. Клиентская форма отправляет данные только на `/api/lead`.

Обработчик приводит поддерживаемые белорусские номера к виду `+375XXXXXXXXX`. Можно указать номер с кодом `+375`, `375`, в национальном формате `80` или девять цифр без кода страны.
